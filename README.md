# Такси Go — демонстрационный сайт с Google Analytics 4

## Состав проекта
- `index.html` — разметка сайта.
- `styles.css` — оформление и адаптация под мобильные устройства.
- `script.js` — калькулятор стоимости и события GA4.

## Запуск
1. Распакуйте архив в отдельную папку.
2. Для простого просмотра можно открыть `index.html` в браузере.
3. Для более надёжной проверки запустите локальный сервер из папки проекта:
   - Python: `python -m http.server 8000`
   - Откройте `http://localhost:8000`

## Подключение GA4
1. Откройте https://analytics.google.com/ и войдите в аккаунт Google.
2. Создайте ресурс Google Analytics 4 (если его ещё нет).
3. В разделе «Администратор» откройте «Потоки данных» → «Веб».
4. Укажите URL сайта. Для локальной демонстрации можно использовать `http://localhost:8000`, если интерфейс GA4 принимает этот адрес для настройки потока.
5. Скопируйте идентификатор измерения, который выглядит примерно так: `G-ABC123DE45`.
6. Откройте `script.js` и замените:
   `const GA_MEASUREMENT_ID = "G-XXXXXXXXXX";`
   на свой реальный ID.
7. Сохраните файл и перезагрузите сайт.
8. Нажмите «Разрешить» в баннере аналитики. До согласия скрипт GA4 не загружается.
9. Проверьте, что в настройках потока включено расширенное измерение, если хотите видеть поддерживаемые автоматические события, например прокрутку.

## Проверка событий
1. Откройте GA4 → «Отчёты» → «В реальном времени».
2. На сайте выберите тариф.
3. Заполните поля маршрута и нажмите «Рассчитать цену».
4. Нажмите «Подтвердить демо-заказ».
5. В GA4 должны появиться события:
   - `page_view` — просмотр страницы (после загрузки тега);
   - `select_tariff` — выбор тарифа;
   - `click_order_cta` — клик по главной кнопке;
   - `calculate_price` — расчёт стоимости;
   - `order_submit` — подтверждение демо-заказа.
6. Для отладки используйте Google Tag Assistant и GA4 → «Администратор» → «Отображение данных» → «DebugView». Для DebugView включите режим отладки через Tag Assistant.

## Важные замечания
- Это макет: реальная диспетчерская, водитель, карта, оплата и серверная отправка заказов отсутствуют.
- Не вводите реальные персональные данные.
- Код намеренно не отправляет адреса маршрута в GA4.
- В `sessionStorage` хранится только выбор согласия в рамках текущей вкладки. Это учебный пример, а не универсальная система управления согласием для production-сайта.
- Перед публикацией на реальном домене настройте баннер согласия и обработку аналитических cookies в соответствии с применимыми требованиями и политиками.
- Данные в отчётах могут появляться не мгновенно; DebugView и Realtime полезны для первичной проверки.
